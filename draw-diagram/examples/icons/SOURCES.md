# Diagram icon sources

Icons for the example diagrams, vendored with
`npm --prefix ../scripts/excalidraw run icons -- <id>@<color> --out examples/icons`.
Each icon is coloured to match the stroke of the role it sits on, so a diagram
keeps one voice. The same file is shared wherever a diagram needs that icon in
that colour.
